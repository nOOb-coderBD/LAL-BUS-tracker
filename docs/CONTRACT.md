# Implementation contract

npm workspaces: `@lal/shared`, `@lal/api`, `@lal/web`. ES modules; Node 24. API port 4000; Vite 5173 proxies `/api` and `/socket.io` to API. API prefix `/api/v1`.

Responses: collections `{items, total, page, limit}`; entities `{item}`. Auth `/auth/me` returns `{user,csrfToken,demoEnabled}` (user null when anonymous); session changes return same. User fields `_id,name,email,role,status,isDemo,emailVerifiedAt`. Cookie `lal_session` httpOnly + SameSite=Lax, Redis-backed opaque session. Mutations require exact allowed Origin AND `X-CSRF-Token` from `/auth/me` (except email/start, email/verify, google, dev-login still require Origin). Socket same-origin cookie, websocket-only, server checks current session/role on subscription and sends `trip:location` initial snapshot; ack `{ok:true,item}` or `{ok:false,error}`.

Auth: `POST /auth/dev-login {persona:'student'|'driver'|'admin'|'unapproved'}` development only with ALLOW_DEMO_AUTH=true. `POST /auth/email/start {email}`; `/auth/email/verify {token}`; no token returned by API. SMTP mail or development inbox described in docs. Admin CLI bootstrap. Driver email proof uses precreated user; no client-selected privileged role.

Models user/driver/bus/route/schedule/trip/location/audit/email-token in `apps/api/src/models.ts`. Auth owns `auth.ts`, core API owns models and `app.ts`. Core exports `createRuntime()` returning `{app,httpServer,io,close}`, no auto-listen; `server.ts` listens. Auth exports `mountAuth(app,redis)`, `sessionMiddleware(redis)` attaching req.auth `{user,csrfToken,sessionId}`, `requireRole(...roles)`, `socketUser(redis,cookie)`; communicate amendments.

Routes `_id,slug,nameBn,subtitle,routeUpText,routeDownText,status,routeGeometry,source`. Schedule `_id,routeId,direction,departureTime,departurePlace,busId,busType,vehicleNumber,daysOfWeek,isStaffOnly,notes,status,sourceKey,source`. Bus `_id,displayNameBn,displayNameEn,fleetNumber,registrationNumber,busType,routeIds,assignedDriverIds,active,approved,isDemo`. Trip `_id,busId,routeId,driverId,direction,status,startedAt,endedAt,isDemo,version,latestPosition`. Live representation adds `freshness:'LIVE'|'STALE'|'OFFLINE'|'ENDED'`, `latestPosition:{latitude,longitude,accuracy,heading,speed,observedAt,receivedAt,simulated}` or null. Active collection only ACTIVE; no ended coordinates. Trip locations POST `{eventId,latitude,longitude,observedAt ISO,accuracy?,heading?,speed?,simulated?:boolean}`. Start `{busId,routeId,direction,scheduleEntryId?}`; end `{}`. GET driver active `{item:trip|null}`. Driver buses uses `/buses?assigned=true` (driver role); admins list `/admin/drivers` joins user/profile and `PATCH /admin/drivers/:userId/approval {approved,allowedBusIds}`. Admin CRUD buses/routes/schedules use whitelisted validation. `GET /admin/audit`.

Shared exports Zod schemas `locationInput`, `tripStartInput`, enums/type exports and `formatTime`, `freshness`. Tests use actual isolated MongoDB + Redis. No in-memory DB substitutes.
